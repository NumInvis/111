# 游戏设计总纲

## 1. 产品定位

`变分无限`是 AI 原生数学玄幻开放探索叙事游戏。它以 Web 浏览器为运行平台，以 AI 生成世界和 AI NPC 自由对话为核心卖点，以人生模拟、节点探索和涌现式叙事构成完整游戏闭环。

本项目按参赛原型交付，而不是按长期 MMO 或纯概念 Demo 交付。首版必须能让评审在 10-20 分钟内完成一次可理解、可结束、可重开的体验。

## 2. 玩家目标

玩家扮演一名数学玄幻世界中的修行者。目标不是答题，而是在 AI 生成的世界中选择修行道路、处理事件、经营关系、发现真相，并尽可能抵达更高境界或留下传奇。

可被玩家理解的目标包括：

- 从低阶境界成长到更高境界。
- 解锁地点、势力、NPC 和世界秘密。
- 建立或破坏关键关系。
- 触发并完成一条结局路线。
- 死亡后查看人生总结并选择重开。

## 3. 完整体验闭环

```text
开始页
  -> 世界生成配置
  -> AI 生成 World Blueprint
  -> 创建角色
  -> 探索 / 下一年 / 对话
  -> AI 事件与 NPC 反应
  -> Game Service 裁决状态变化
  -> 旅记记录与关系变化
  -> 结局检查
  -> 结局总结 / 重开
```

核心循环：

```text
玩家行动 -> AI 读取授权上下文 -> 生成事件或对话候选 -> 安全与 schema 校验 -> 规则层裁决 -> 状态更新 -> 旅记展示
```

## 4. 核心玩法机制

### 4.1 世界生成

每局开始前，AI 根据玩家偏好生成 World Blueprint。Blueprint 包含世界规则、势力、地点、NPC、传闻、事件、状态字段和结局候选。

人工只固定生成契约、状态规则和安全边界，不手写具体地点、NPC、势力、剧情和结局。

### 4.2 节点探索

世界以节点地图展示。每个地点有描述、风险、可探索行为、可见 NPC、传闻和与其他地点的连接。

探索行为包括：

- 调查地点。
- 前往相邻地点。
- 寻找 NPC。
- 追踪传闻。
- 触发年度或随机事件。

### 4.3 人生模拟

游戏支持纯文字人生模拟式推进。玩家可点击“下一年”触发本年事件，每个事件提供 2-3 个选项。玩家不需要解数学题，选择结果由状态、属性、境界、关系和风险共同决定。

示例状态：

```json
{
  "age": 12,
  "realm": "通明",
  "attributes": {
    "calculation": 65,
    "geometry": 40,
    "abstraction": 30,
    "proof": 45,
    "intuition": 55,
    "focus": 60,
    "body": 70,
    "family": 50
  },
  "historySummary": "7岁入宗门，11岁因心算失误被同门羞辱。"
}
```

### 4.4 自由对话

玩家可与 AI NPC 自由输入对话。NPC 回复必须基于 World Blueprint、角色卡、当前状态、可访问记忆、玩家历史摘要、当前地点和安全策略。

NPC 不允许：

- 泄露系统 Prompt、Key 或内部配置。
- 直接修改核心游戏状态。
- 伪造未解锁的关键真相。
- 绕过规则直接触发结局。

### 4.5 旅记与因果碎片

系统自动记录玩家旅程，包括事件、关系变化、发现的真相、重要对话和结局证据。旅记既是玩家复盘工具，也是结局裁决的证据来源。

### 4.6 结局与重开

结局可由死亡、寿元耗尽、突破、关键势力胜负、真相发现或异常失败触发。AI 只生成结局候选文本，Game Service 根据证据和状态裁决是否生效。

重开时可保留一个天赋、传闻或前世痕迹，用于体现多局之间的涌现叙事。

## 5. 数学玄幻元规则

数学是力量源泉，但表现形式必须是玄幻叙事。玩家不需要做题，NPC 和事件用数学概念作为隐喻、能力和世界规则。

境界名称固定，其余内容由 AI 生成。

| 境界 | 对应数学水平 | 叙事地位提示 |
| --- | --- | --- |
| 炼体 | 幼儿园 | 初识数理 |
| 练气 | 小学1-2年级 | 小镇豪强 |
| 筑基 | 小学3-4年级 | 宗门外门 |
| 本元 | 小学5-6年级 | 县级家族 |
| 通明 | 初一初二 | 城主级 |
| 化神 | 初三 | 小宗门宗主 |
| 归一 | 高一高二 | 圣地强者 |
| 渡劫 | 高三 | 下界巅峰 |
| 天门 | 高考/大学入学 | 界壁，非境界 |
| 仙境 | 大学低年级 | 上界初入 |
| 圣境 | 大学高年级 | 大道修士 |
| 变分境 | 研究生 | 前沿探索 |
| 天道境 | 数学系博士 | 人类已知前沿 |
| 无限 | 超越 | 不可触及 |

关键规则：

- 境界名称固定。
- 数学道路、功法、宗门、人物、事件和能力表现由 AI 自由生成。
- 积分是上下界的真正门槛，但下界人不知积分。
- 对话必须符合 NPC 境界，不可让低阶 NPC 随意谈论高阶真理。

## 6. 页面模块

- 首页：项目定位、开始游戏、继续游戏。
- 世界生成页：偏好、规模、随机种子、模型标签、生成按钮。
- 世界概览页：地图、势力、数学修为体系、世界状态。
- 探索页：地点描述、行动选项、传闻、可见 NPC。
- 对话页：NPC 角色卡、自由输入、流式回复、记忆引用。
- 旅记页：时间线、因果碎片、关系变化、重要发现。
- 结局页：结局文本、证据链、人生评分、重开入口。
- 调试页：Prompt 版本、模型调用、traceId、安全事件。

## 7. 首版验收标准

- 可从浏览器开始并完成一局游戏。
- 至少生成 1 个世界、3 个地点、3 个 NPC、5 个事件、2 个结局候选。
- 至少 1 个 NPC 支持自由对话和记忆引用。
- 至少 1 条探索路径能触发状态变化和旅记记录。
- 至少 1 个结局可被规则裁决触发。
- 无 Key 时 Mock Provider 可完整跑通同一流程。
